# 最近聊天记录浮层改造 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 starring 项目侧边栏的"最近聊天记录"从 `.fill` 填充区移除，改造成在"创建新对话"导航项行尾添加 History 图标，hover 时弹出 a-popover 浮层显示最近聊天记录。

**Architecture:** 抽出独立组件 `NewChatNavItem.vue` 封装"创建新对话链接 + History 触发器 + Popover + 折叠态分支"；`ConversationNavSection.vue` 复用，仅移除中键删除；`AppLayout.vue` 移除 `.fill` 旧引用，引入 `NewChatNavItem`。所有事件 handler 透传，AppLayout 中现有的 handler 不变。

**Tech Stack:** Vue 3 (Composition API) / ant-design-vue 4.x (a-popover) / lucide-vue-next / less / pnpm / Docker Compose 热重载

**Reference Spec:** `docs/vibe/2026-07-26-最近聊天记录浮层改造.md`

---

## File Structure

## 项目约定适配说明

- **无前端测试框架**：`web/package.json` 未装 vitest/jest/@vue/test-utils。按 project_memory 约束"本地环境无依赖不强制安装测试"，本计划用 `pnpm lint` + `pnpm build` + 手动测试 checklist 替代自动测试。
- **TDD 适配**：每个任务改为「实现 → lint → build → 手动验证 → commit」循环，而非「写失败测试 → 实现」。
- **Docker 热重载**：开发在 `docker compose up -d` 启动的 `web-dev` 容器中进行，本地改代码自动热重载，无需重启容器。
- **提交规范**：Conventional Commits + 中文提交信息，标题简洁，描述具体改动和原因。每个任务结束独立提交。
