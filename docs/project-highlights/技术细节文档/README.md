## 🔑 核心技术亮点

### 1. 文档切割策略（RAGFlow-like）

- **6种分块算法**：通用/书籍/法律/QA/语义/分隔符，适配不同文档类型
- **近似Token计数**：无需引入tiktoken，快速估算文本长度
- **分层合并机制**：基于标题层级智能合并，保持语义完整性

### 2. 检索准确率优化

- **混合检索策略**：向量检索 + BM25全文检索，优势互补
- **RRF融合算法**：Reciprocal Rank Fusion，平衡语义与关键词匹配
- **图检索增强**：Personalized PageRank实现多跳实体扩散

### 3. 知识图谱抽取

- **Schema约束抽取**：用户自定义实体类型和关系类型
- **Few-shot学习**：提供示例提高抽取准确性
- **增量更新机制**：支持文档更新时图谱同步更新

### 4. Token上下文管理

- **实时监控**：每次LLM调用记录Token使用情况
- **上下文窗口预警**：接近限制时自动触发摘要压缩
- **多模型适配**：动态获取不同模型的上下文窗口大小

### 5. 多格式文档解析

- **统一Markdown输出**：所有格式转换为Markdown，简化后续处理
- **OCR多引擎支持**：RapidOCR/MinerU/PaddleOCR等多方案可选
- **表格智能处理**：自动识别表格结构，转换为Markdown表格

### 6. 安全防护机制

- **双重过滤机制**：关键词黑名单 + LLM语义审查
- **Prompt注入防护**：系统级约束，防止恶意指令注入
- **合规性检查**：自动检测内容合规性，保障系统安全
