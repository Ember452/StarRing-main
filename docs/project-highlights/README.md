# 项目技术亮点文档索引

本目录收录了 **starring** 项目的核心技术亮点文档，涵盖多 Agent 系统架构、RAG 与知识图谱融合、高性能异步 API 设计、状态持久化、知识库管理、长上下文管理、沙盒环境安全隔离、异步任务队列等核心模块的深度技术解析。

这些文档不仅是技术实现的详细说明，更提供了**简历写法建议**、**量化指标**和**面试问答要点**，帮助开发者将技术成果转化为有竞争力的简历亮点。

## 📚 文档导航

### 1. 多Agent系统架构设计

**文件**: [项目简历写法/01-多Agent系统架构设计.md](./项目简历写法/01-多Agent系统架构设计.md)

**核心亮点**:
- 基于 LangGraph v1 构建，支持 3 种编排模式（Orchestrator-Worker、Supervisor、Workflow）
- 10 层中间件栈设计，实现文件系统、知识库检索、子智能体委派等核心能力
- 多后端状态持久化（PostgreSQL/SQLite/Memory），状态恢复成功率 100%

**技术关键词**: `LangGraph v1` `多Agent系统` `状态机` `Checkpointer` `中间件模式` `MCP`

### 2. RAG + 知识图谱融合架构

**文件**: [项目简历写法/02-RAG+知识图谱融合架构.md](./项目简历写法/02-RAG+知识图谱融合架构.md)

## 🔬 技术细节文档

除了上述核心架构亮点外，项目还包含大量**技术细节实现**，这些细节往往是面试官深入追问的重点。我们在 `技术细节文档/` 目录下提供了 8 个独立的技术细节分析文档：

### 核心技术细节

1. **[文档切割策略](./技术细节文档/01-文档切割策略.md)**
   - 6种预设分块策略（General/QA/Book/Laws/Semantic/Separator）
   - 近似Token计数算法，分层合并策略
   - **改进空间**：引入tiktoken精确计算，语义分块模型池化

2. **[Embedding模型选择](./技术细节文档/02-Embedding模型选择.md)**
   - bge-m3模型选型，批量编码优化
   - 模型缓存机制，重试策略设计
   - **改进空间**：动态batch_size，模型实例单例缓存

3. **[检索准确率优化](./技术细节文档/03-检索准确率优化.md)**
   - 向量检索 + BM25 + 图检索三路融合
   - RRF融合算法，相似度阈值过滤
   - **改进空间**：引入Re-Ranker，三方融合计算

4. **[知识图谱抽取](./技术细节文档/04-知识图谱抽取.md)**
   - LLM抽取Prompt设计，Schema约束机制
   - 并发控制，实体归一化
   - **改进空间**：Few-shot示例，实体链接，Schema校验

5. **[文档解析处理](./技术细节文档/05-文档解析处理.md)**
   - 多格式解析（PDF/DOCX/XLSX/PPTX）
   - OCR集成（MinerU/PaddleX/DeepSeek）
   - **改进空间**：增量解析，表格结构识别

6. **[Prompt工程实践](./技术细节文档/06-Prompt工程实践.md)**
   - 分层Prompt设计，知识库强制检索
   - Few-shot示例，安全约束
   - **改进空间**：Prompt注入防护，输出审查

7. **[Token计算优化](./技术细节文档/07-Token计算优化.md)**
   - 实时Token监控，上下文管理
   - 分级预警机制，摘要压缩
   - **改进空间**：tiktoken精确计算，用量告警

8. **[知识库安全防护](./技术细节文档/08-知识库安全防护.md)**
   - 双重审查架构（关键词 + LLM）
   - Prompt注入防护，输出内容审查
   - **改进空间**：云端敏感词库，异步审查

- ✅ 基于真实代码路径，无理论空谈
