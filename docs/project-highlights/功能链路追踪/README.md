## 阅读建议

### 对于面试准备者

建议优先阅读核心业务链路（⭐⭐⭐）和智能体能力链路（Skills/MCP/工具），理解每个链路的设计亮点和技术细节。面试时可以从以下角度展开：

1. **架构设计**：为什么要这样分层？各层的职责边界是什么？
2. **技术难点**：流式响应如何实现？中断恢复如何保证状态一致性？
3. **性能优化**：哪里有性能瓶颈？如何优化的？
4. **可扩展性**：如果要增加新功能，应该改哪里？

### 对于代码贡献者

建议先阅读 [系统全景图.md](../系统全景图.md) 建立全局认知，再按重要程度阅读链路文档，最后结合 [ARCHITECTURE.md](../../../ARCHITECTURE.md) 中的架构不变量理解设计约束。

### 对于项目学习者

建议按照链路清单顺序依次阅读，每个链路建议：

1. 先看"链路概览"建立整体认知
2. 再看"详细链路追踪"理解具体实现
3. 最后看"设计亮点"和"可改进之处"形成深度思考
