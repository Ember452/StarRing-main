# starring-cli

starring command line client.

First-stage scope:

- remote management through `~/.starring/config.toml`
- browser login
- API Key import through `--api-key`
- `whoami`, `status`, and `logout`
- server discovery and compatibility check for starring `>=0.7.1`
- `starring agent eval` for running existing Langfuse dataset experiments with a logged-in remote
